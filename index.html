Intel Labs · 2017–2019
Distributed Autonomous Swarm Robots
A fully distributed swarm where ground robots and drones coordinate without any central server — each making local decisions from shared state and dynamic anchor selection. Demonstrated as a working PoC; resulted in five US patents and featured at ISSCC 2019 on a custom 22nm CMOS robot SoC.
SwarmMulti-Robot22nm SoCISSCC
Intel Labs · 2019–2022
AVIO — Event-Based Visual Inertial Odometry
Visual odometry built on event cameras — neuromorphic sensors firing at microsecond resolution. AVIO fuses asynchronous event streams with IMU data for low-latency localization in fast-motion and low-light conditions where conventional cameras fail. Best Paper, IEEE CONECCT 2023.
Event CamerasVisual OdometryBest Paper
Intel Labs · 2019–2021
KB-RRT — Kinematic Path Planner
A bi-directional RRT that respects real robot kinematic constraints, generating smooth, executable trajectories rather than geometric paths. Extended to PG-RRT using Gaussian Mixture Models for probabilistic environment representation. Published at ICRA 2019 and IROS 2021.
Path PlanningRRTICRAIROS
Samsung R&D · 2022–2023
Deep RL Coverage Path Planner
Deep reinforcement learning agents trained to solve coverage planning — ensuring a robot covers every point in an unknown environment with minimal overlap. Extended to multi-robot coordination where agents divide territory without explicit communication.
