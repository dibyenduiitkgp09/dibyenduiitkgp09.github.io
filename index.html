Intel Labs
2017 – 2019
Distributed Autonomous Swarm Robots
Built a fully distributed swarm system where ground robots and drones coordinate autonomously without any central server. Each robot makes local decisions using shared state and dynamic anchor selection. Demonstrated a working PoC and resulted in 5 US patents. Featured at ISSCC 2019 with a custom 22nm CMOS robot SoC.

Intel Labs
2019 – 2022
AVIO — Asynchronous Event-Based Visual Inertial Odometry
Developed a novel visual odometry system using event cameras — neuromorphic sensors that respond to pixel-level brightness changes at microsecond resolution. AVIO fuses asynchronous event streams with IMU data for accurate, low-latency localization in fast-motion and low-light environments where conventional cameras fail. Best Paper Award at IEEE CONECCT 2023.

KB-RRT — Kinematic Path Planner for Cluttered Environments
Designed a bi-directional RRT path planning algorithm that respects kinematic constraints of real robots, generating smooth, executable trajectories rather than geometric paths. Extended to PG-RRT using Gaussian Mixture Models for probabilistic environment representation. Published at ICRA 2019 and IROS 2021.
